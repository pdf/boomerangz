# About Boomerangz

Boomerangz is an open-source OpenZFS snapshot and replication manager for
continuously connected and intermittently connected systems.

The project is released under the [MIT License](https://github.com/pdf/boomerangz/blob/main/LICENSE).
Source code, issues, and releases are hosted on
[GitHub](https://github.com/pdf/boomerangz).

## Documentation versions

The documentation labelled **Development** follows the unreleased `main`
branch. Use the version menu in the navigation bar to select documentation
captured from a particular release tag. Released documentation remains at its
versioned URL even after development moves on. Before the first release, the
site opens on Development documentation. Afterward, the site opens on the
latest release by default while Development remains separately selectable.

## AI disclosure

Boomerangz’s design, technical guidance, and verification were performed by a
human. The majority of the implementation code was written by a large language
model.
